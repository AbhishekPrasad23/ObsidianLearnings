

1. **Does the problem ask for a _min/max_ value subject to constraints?**  
    → Likely binary search on answer.
    
2. **Can you phrase it as: “Find the smallest x where condition(x) is true”?**  
    → Yes → Binary search candidate.
    
3. **Is brute force over the answer range too slow, but checking a candidate is easy?**  
    → Yes → Binary search helps.
    
4. **Is there an _ordered_ sequence or _range_ of possible answers?**  
    → Yes → Good sign.
